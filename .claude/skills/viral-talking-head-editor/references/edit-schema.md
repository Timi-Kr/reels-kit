# edit.json — the single file that drives the Remotion render

Location: `public/projects/<slug>/edit.json`. TypeScript types: `src/types.ts`.
All times are **frames** at `fps` (30). `init_edit.py` creates it; you then edit scenes/camera; `place_sfx.py` fills `sfx`.

## Scene types → how the frame is laid out (`src/Edit.tsx`)
| type | scene component box | speaker | captions default |
|---|---|---|---|
| `captions` | none (use for camera moves only) | full frame | y 0.70 |
| `ui` | **lower half** 1080×960 | darkened + blurred | y 0.53 (above the UI) |
| `halfscreen` | **top half** 1080×960 | slides into bottom half, cropped at `faceY` | y 0.535 (on the seam) |
| `fullscreen` | whole frame | hidden (voice continues) | hidden unless `"captions":"show"` |

Scene components get `{edit, scene, slug, width, height, ...props}` and run in a `<Sequence>` (frame 0 = scene start).
The wrapper adds an 8-frame entry (slide/scale + fade) and 6-frame fade out — design the inner motion on top of that.

Scene `look` (`auto | paper | white | grey | dark | accent`) comes from the plan page's per-line Background; render the scene's background with `<SceneBackground look={pickLook(scene.look, '<role default>')}>`.

## Shared building blocks (`src/components/`)
- `design.tsx`: `MinimalBackground` (tone warm/cold/dark, grid, halftone, cast shadow, grain, accentGlow), `Grid`, `Halftone`, `CastShadow`, `Grain`, `Reveal` (up/down/left/right/scale/fade + blur), `useSpring` + `SPRINGS` (snappy / default / heavy — use for every enter, exit, move), `useSpringIn` (legacy), `Drift`, `Title` (sans + script words, light gradient), `WriteOn` (letter-by-letter), `ObjectImage` (cut-out with cast shadow + texture), `GlassCard` (dark/light glass UI), `Cursor`, `DepthMark`, `shade()`.
- `ui.tsx`: `ChapterTracker` (numbered circles that fill), `Slider`.
- `glow.tsx` (**all UI pieces + `SceneBackground` looks**, see visual-training PART 5 and the `UIKit` composition): `SceneBackground` (paper / white / grey / dark / accent, sets tone), `pickLook`, `GlowCard` (light lit card / `frosted` / dark rim-lit), `Bloom`, `GlowBackground` + `ToneProvider`, `BigNumber`, `LineChart`, `BarChart`, `Ring`, `CheckBurst`, `GlassIcon`, `Notification`, `LiveActivity`, `PromptBar`, `Segmented`, `Phone` (RARE — real app screenshots in an iPhone, only for 'using this app' moments: `switchAt` pushes, `taps`, `scroll`), `MotionClip` (a motion-reel / external clip as a full-screen scene), `INKS` / `useInk` (iOS label colours), `accentInk`, `useProgress`, `luminance`.
- `Captions.tsx`, `TalkingHead.tsx`, `Audio.tsx` (voice + sfx + music with ducking under scenes).
Add new reusable pieces to `glow.tsx` (lit UI) or `ui.tsx` when they'll recur (chapter UIs, counters, charts) — keep per-edit one-offs in the project folder.

## Fonts (`src/fonts.ts`)
Sans: `Creato Display` (default, local, weights 100–900 + italics — same font as the reference edit), `Inter`, `Manrope`, `DM Sans`. Script: `Cormorant Garamond` (default), `Playfair Display`, `EB Garamond`, `Instrument Serif`.
To add another font: drop the files in `public/fonts/`, add a `loadLocal(...)` + an entry in `FONTS`, and add its name to `SANS`/`SCRIPT` in `make_plan_page.py`.
